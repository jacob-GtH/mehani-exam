# منصة التدريب على اختبارات الاعتماد المهني

Next.js + TypeScript + Tailwind + Sanity. مبنية للنشر على Vercel.

## المتغيرات المطلوبة

أنشئ ملف `.env.local` في جذر المشروع (ولا ترفعه إلى GitHub):

```
NEXT_PUBLIC_SANITY_PROJECT_ID=رقم مشروع Sanity
NEXT_PUBLIC_SANITY_DATASET=production
SANITY_WRITE_TOKEN=توكن بصلاحية Editor (سري)
NEXT_PUBLIC_SITE_URL=https://دومينك.com
ADMIN_PASSWORD=كلمة مرور طويلة للوحة التحكم
ADMIN_SECRET=نص عشوائي طويل 32 حرفًا فأكثر
```

> `SANITY_WRITE_TOKEN` و`ADMIN_PASSWORD` و`ADMIN_SECRET` أسرار: لا تضعها في الكود ولا في GitHub.

## التشغيل محليًا

```bash
npm install
npm run seed      # اختياري: ينشئ اختبارًا تجريبيًا واحدًا
npm run dev       # http://localhost:3000
```

## لوحة التحكم

- الدخول: `/admin` (الرابط غير ظاهر للزوار عمدًا).
- **الاختبارات:** إنشاء وتعديل ونشر وحذف، وإدارة الأسئلة واحدًا واحدًا.
- **استيراد:** لصق أسئلة من Word أو Excel لعدة اختبارات دفعة واحدة (زر «ضع القالب الجاهز» يوضح الصيغة).
- **الإحصاءات:** المحاولات ونسب النجاح وأصعب الأسئلة.
- الاختبار الجديد يبقى **مسودة** حتى تفعّل «منشور» من صفحته.

## النشر على Vercel

1. ارفع المشروع إلى مستودع GitHub.
2. في Vercel: Add New → Project → اختر المستودع.
3. في Environment Variables أضف المتغيرات الستة أعلاه، مع جعل `NEXT_PUBLIC_SITE_URL` هو دومينك الحقيقي.
4. اضغط Deploy.
5. من Settings → Domains أضف دومينك واتبع تعليمات DNS.
6. أعد النشر (Redeploy) بعد تغيير أي متغير.

## بعد النشر (للظهور في جوجل)

1. سجّل الموقع في Google Search Console (Domain property).
2. أرسل `https://دومينك.com/sitemap.xml` من قسم Sitemaps.
3. اطلب فهرسة الصفحة الرئيسية وصفحتين أو ثلاث من الاختبارات.
4. غيّر `SITE.name` في `src/lib/site.ts` إلى اسم فريد غير عام.
5. اكتب في كل اختبار وصفًا فريدًا من لوحة التحكم، وأضف عددًا جيدًا من الأسئلة.

## ملاحظات

- التحديثات من لوحة التحكم تظهر في الموقع العام فورًا.
- الموقع تدريبي مستقل وغير تابع للجهة الرسمية، وعبارة التنبيه في الفوتر يجب أن تبقى.
- لا يوجد حد لمحاولات كلمة مرور الإدارة، فاختر كلمة قوية.
- حذف اختبار يحذف أسئلته وإحصاءاته نهائيًا.
